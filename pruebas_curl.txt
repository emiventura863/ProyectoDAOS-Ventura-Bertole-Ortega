HOGARYA - DAOS - Pruebas reproducibles S01, S02 y S03
Base: http://localhost:8080
Requisitos: iniciar Spring Boot y cargar datos_prueba.sql una sola vez en tablas vacias.
Ejecutar en PowerShell (curl.exe); los JSON usan comillas escapadas para Windows PowerShell 5.1.
Ejecutar en orden. Las pruebas de escritura modifican la base; restaurar los datos iniciales en una base de prueba para repetir.
Los codigos son esperados por revision estatica, no ejecucion de estos comandos.
Fecha de referencia: 25/11/2026. Las pruebas de alta de incidentes requieren contrato 1 vigente (01/11/2026 a 31/10/2027); los pagos fechados requieren fecha actual >= 25/11/2026.

=== S01 FACTURAS ===
Consultar contrato | HTTP 200
curl.exe -i -X GET "http://localhost:8080/contratos/1"

Listar | HTTP 200

Vencidas | HTTP 200
curl.exe -i -X GET "http://localhost:8080/facturas?estado=VENCIDA"
